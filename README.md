# Rahul Varma - Portfolio

Professional portfolio of Rahul Varma, Senior Software Engineer. Built with Next.js, Tailwind CSS, and Framer Motion.

## Features
- **Modern Aesthetic**: Dark-themed, glassmorphic design.
- **Interactive Timeline**: Professional journey with scroll-linked animations.
- **Tech Arsenal**: Comprehensive view of skills across various domains.
- **Projects**: High-impact enterprise and independent projects.

## Tech Stack
- **Framework**: Next.js
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React

## Development
```bash
npm install
npm run dev
```

## Production
```bash
npm run build
```
The static output is generated in the `out/` directory.
